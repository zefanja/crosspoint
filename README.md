# Versfest (crosspoint)

Web-Lernplattform mit Spaced Repetition (FSRS) – kompatibel mit Anki.
Bibelverse im Browser lernen und jederzeit samt Lernstand nach Anki exportieren.

- Anforderungen: [SPEC.md](SPEC.md)
- Entwicklung: [CLAUDE.md](CLAUDE.md)
- Deployment (Portainer): [docs/deploy.md](docs/deploy.md)

Der Notiztyp „Bible Memorizer“ und der Kartengenerator stammen aus
[zefanja/bible-memorizer](https://github.com/zefanja/bible-memorizer) (GPL-3.0).

Lizenz: AGPL-3.0 (siehe [LICENSE](LICENSE)), da die verwendete `anki`-Bibliothek unter
AGPL-3.0 steht.
